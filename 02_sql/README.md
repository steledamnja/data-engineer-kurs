# SQL | ITBootCamp Data Engineering

This directory contains SQL exercises and homework assignments completed as part of the ITBootCamp Data Engineering program.

The exercises were completed using Databricks SQL, focusing on querying, filtering, and transforming structured data.

## Environment

- Platform: Databricks
- Language: SQL
- Dataset: `matches_flat`
- Database schema: `bootcamp.northern_star`

The dataset contains football match records, including information about teams, match results, stadiums, referees, attendance, and match statistics.

### Topics Covered

**Basic SQL Queries**
- SELECT and FROM
- WHERE conditions
- DISTINCT
- ORDER BY
- LIMIT

**Filtering and Logical Operations**
- Comparison operators
- AND and OR
- LIKE and ILIKE
- Date and time filtering

**Data Transformation**
- Column aliases using AS
- Calculated columns
- COALESCE for handling NULL values
- CAST for data type conversion
- CONCAT for combining values

**Functions and Aggregation**
- COUNT
- LENGTH
- DATE
- DATE_FORMAT

## Learning Objectives

The exercises focus on developing practical SQL skills, understanding how queries process structured data, and preparing for more advanced data transformation tasks.

These skills provide a foundation for working with databases and building data pipelines.

## Notes

The SQL scripts were developed using the ITBootCamp training dataset and require access to the corresponding database tables to execute.
